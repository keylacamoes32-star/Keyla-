# 14-Day Wellness Quiz Sales Page

A responsive, mobile-first English (US) sales funnel for a 14-day wellness/weight-management plan.

## Features
- Four-step interactive quiz with answer buttons and progress indicator.
- Personalized, general wellness result based on quiz answers.
- Three individual checkout buttons:
  - Basic — $27: https://checkout.escalepay.com/8092275
  - Plus — $70: https://checkout.escalepay.com/9898627
  - Pro — $120: https://checkout.escalepay.com/4959989
- Responsive layout for mobile and desktop.
- Wellness disclaimer; no guaranteed weight-loss claims.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open the repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to publish the site; the public URL will appear in the Pages settings.

## Before publishing
- Replace the placeholder `support@example.com` email in the footer with a real support address, or remove the contact link.
- Confirm that the Basic, Plus and Pro descriptions accurately match what buyers receive.
- Add your real business name, privacy policy, refund policy and terms where appropriate.
- Test each checkout link on desktop and mobile.

The quiz runs in the visitor's browser and does not store or send answers to a server. The page is educational and is not medical advice.
